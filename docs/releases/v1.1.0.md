安卓安装包（正式签名）：下载 babypaper-v1.1.0.apk，点开安装，系统提示「未知来源」时允许一次即可。已经装了 v1.0.0 的，直接装这个新版覆盖就行，存档和生词本都会保留。

这一版的变化：

- 新图标：手绘的「宝」字，「玉」上那一点画成一粒胶囊。安卓 13 以上可以开「主题图标」，让它跟着壁纸变色。
- 点开动画：每次启动先写出「宝」字，胶囊落下，再从胶囊那一点展开进入界面，不到两秒。点一下屏幕可以跳过；系统开了「减弱动态效果」时不播放。
- 启动时不再闪白屏，从点图标到进入界面都是同一种绿色。

也可以不装 APK：手机浏览器打开在线版 https://gustavpharm.github.io/babypaper/ ，菜单里选「安装应用 / 添加到主屏幕」，就是 PWA 版。
