安卓安装包（正式签名）：下载 babypaper-v1.2.0.apk，点开安装，系统提示「未知来源」时允许一次即可。已经装了旧版的，直接装这个新版覆盖就行，存档和生词本都会保留。

这一版的变化：

- 词库从 623 条扩到 686 条。新增三个分类：实验常用细胞（20 条，含培养条件）、实验常用试剂（22 条，含毒性、用途和常用配比）、天然药物化学（36 条，含青蒿素、小檗碱等成分的结构图）。
- 修复表格读不了的问题：导入文献里的 Markdown 表格和 HTML 表格现在显示为真正的表格，不再被压成一串数字，表格里的术语也能点开查。
- 配图从 186 张增至 206 张。

也可以不装 APK：手机浏览器打开在线版 https://gustavpharm.github.io/babypaper/ ，菜单里选「安装应用 / 添加到主屏幕」，就是 PWA 版，内容和 APK 一致。
