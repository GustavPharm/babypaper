安卓安装包（正式签名）：下载 babypaper-v1.2.1.apk，点开安装，系统提示「未知来源」时允许一次即可。已经装了旧版的，直接装这个新版覆盖就行，存档和生词本都会保留。

这一版的变化：

- 修复手机上阅读页右边被切掉的问题：导入的文献标题是很长的文件名时，现在会自动换行，不再把页面撑得比屏幕宽，点词弹出的词条卡和按钮也不会再跑出屏幕。
- 修复谱图数据里化学符号显示成原始代码的问题：$^{13}$C、$\delta$、$C_{3}$ 这类写法现在显示为真正的上标、下标和希腊字母，SMILES 结构式字符串收成带标注的小代码块。已经存档的文献不用重新导入，打开就是修好的。

也可以不装 APK：手机浏览器打开在线版 https://gustavpharm.github.io/babypaper/ ，菜单里选「安装应用 / 添加到主屏幕」，就是 PWA 版，内容和 APK 一致。
